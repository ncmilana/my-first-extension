# C++ Include Counter

**Автор:** Николаевская Милана, группа М3113
**Название плагина:** my-first-extension

## Описание

Плагин для Visual Studio Code, который подсчитывает количество директив `#include` в текущем открытом файле C или C++. Создан в рамках лабораторной работы №3.

## Возможности

- Добавляет команду **Count C++ Includes** в палитру команд VS Code.
- Проверяет, является ли открытый файл языком C или C++.
- С помощью регулярного выражения находит все директивы `#include <...>` и `#include "..."` и выводит их точное количество.
- Если открыт файл другого формата, выводит предупреждение.

## Запуск
1. Выполнить `npm install`.
2. Выполнить `npm run compile`.
3. Нажать `F5` в VS Code.
4. В новом окне открыть любой `.cpp` файл.
5. Вызвать палитру команд (`Cmd + Shift + P` или `Ctrl + Shift + P`) и ввести **Count C++ Includes**.
