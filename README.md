# my-first-extension

**Автор:** Николаевская Милана, группа М3113
**Название плагина:** my-first-extension

## Описание
Плагин для Visual Studio Code, созданный в ходе лабораторной работы «Создание плагина». Добавляет в редактор VS Code новую команду.

## Возможности
- Добавляет команду "Hello World" в палитру команд.
- При вызове команды показывает уведомление: «Hello World from my-first-extension!».

## Запуск
1. Клонировать репозиторий.
2. Установить: `npm install`.
3. Собрать проект: `npm run compile`.
4. Нажать `F5`
5. В новом окне вызвать палитру команд (`Cmd + Shift + P`) и ввести "Hello World".
